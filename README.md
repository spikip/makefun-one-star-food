## About this entry

The sentence is a one-star review written by a tourist from
another planet, and it does both jobs the bounty asks for in a
single breath. The complaint is alien in scale: gravity is
excessive and the toilet queue is interstellar, grievances only
a visitor from light-years away would file. Then the twist turns
the whole review around, because the dumplings alone are worth
the 40-light-year trip, a compliment so specific it can be
pictured, steamed and eaten. The deadpan voice never breaks,
the complaint and the praise sit side by side, and the line
stays well inside the two hundred character cap. The program
holds the sentence, checks it against that cap, and writes it
to /output/entry.txt exactly as the bounty requires.
